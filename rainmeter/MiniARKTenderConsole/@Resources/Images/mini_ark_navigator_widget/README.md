# mini_ark Navigator prototype

A native HTML/CSS/JS reconstruction of the locked mini_ark Navigator visual design.

## Run

From this folder:

```powershell
python -m http.server 8789
```

Then open:

`http://127.0.0.1:8789`

## Important

The images under `reference/` are documentation only. The rendered interface is rebuilt from native controls and modular assets.

See `HANDOFF.md` for integration notes.
