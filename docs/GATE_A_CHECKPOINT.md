# Gate A checkpoint - 2026-09-16

This is a development checkpoint, not Journey graduation or authorization for
broad cleanup. Confidence in identity is not confidence in action.

- 139 disposable-fixture tests pass on Windows with Python 3.14 and Pillow 12.2.
- The isolated publication snapshot runs 139 tests: 134 pass and five private
  conversation-fixture tests skip intentionally. No private fixture is published.

See [Recovery and privacy contracts](RECOVERY_AND_PERCEPTION_POLICY.md).

## Reproduce

Install Python 3.11 or newer and the dependencies in `requirements.txt`, then run
`python -m unittest discover -s tests -q`. Windows is required for the full
filesystem semantics suite. FFmpeg/ffprobe are optional local prerequisites for
video reconnaissance, not bundled executables. Tests use disposable providers;
no production media repair provider is installed.

Launch the current browser Navigator with `start_mini_ark.ps1`. The Rainmeter
bundle and its embedded reference mockup are retained from earlier work; their
static example readouts are not current telemetry. The local bridge/Navigator is
the current tested stewardship control surface.

## Still open

Dependency domains are not exhaustively covered. Retirement/authority evidence
needs stronger authentication. Cross-volume resume and rollback, power-loss
durability, handle-based race protection, remaining legacy workflow enforcement,
and automatic Patrol scheduling remain incomplete. New derivative-recovery
attempts retain crash evidence but do not yet automatically resume.
Long-path handling across production asset workflows is not certified; the
publication check exposed overlong fixture names, now shortened and isolated.

Media reconnaissance is bounded, not a complete corpus recovery or health audit.
First-frame/sample decode is not whole-file usability proof. Registry policies
do not yet follow all relocation aliases. Trusted provider contracts are not
OS-level sandboxes. A passing suite does not close any of these gaps.

## Publication boundary

This repository carries implementation, fixtures, contracts, and selected UI
artwork. Local databases, personal-media inventories, recovery logs, generated
Shadow evidence, and private reports are excluded. Machine-specific HEXSEED
placement configuration remains explicit project configuration, not portable
default authority. Review it before use on another machine.
