## Verified code

Bounded discovery, resumable inventory/hashing, budgets/process locks, fail-closed
source holds, inherited SEALED/LIMITED/OPEN policy, structured reference evidence
with explicit coverage/UNKNOWN, persistent Patrol controls, and journal/recovery
protections are implemented. Navigator exposes dependency coverage and validates
request bodies, confirmations and private-resource boundaries.

The typed operation-bound verifier binds paths/scopes, proposal/approval, source
identity, evidence references and expiry. Evidence is rechecked before journal
intent and mutation and recorded before rename. Ten disposable-fixture tests
cover move/undo, forgery, expiry/revocation, drift, holds, occupants and interruption.
In-memory knowledge/need contracts exist; persistent behavioral user models do not.
